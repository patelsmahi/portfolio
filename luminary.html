Luminary

Luminary is a navigation app built by App Team Carolina to help UNC Chapel Hill students find safe, accessible routes around campus. It allows users to plan paths that avoid obstacles like construction and uneven terrain, and includes a community feature for reporting new barriers in real time.

Problem Statement: Luminary users had difficulty viewing the app comfortably in different lighting conditions, especially without a light mode option.

Role: UI/UX Designer
Duration: 3 Months

Project Overview & Outcome

Luminary is one of the many projects App Team Carolina has developed. This one specifically focused on solving accessibility issues for students navigating the UNC Chapel Hill campus. The app provides a platform for users to find safe and accessible routes, avoiding obstacles like construction and uneven terrain. Additionally, it includes a report feature that allows users to report new barriers in real time, ensuring that the app remains up-to-date and useful for all students.

Key Issue: After user testing, some issues needed to be updated The main issue identified was the lack of a light mode option , which made it difficult for users to view the app comfortably in different lighting conditions. This was particularly problematic for users with visual impairments or those who preferred a lighter interface for better readability.

Design Outcome: I implemented a light mode option in the app, allowing users to switch between light and dark themes based on their preferences and lighting conditions. This update significantly improved the user experience, making the app more accessible and user-friendly for all students navigating the campus. This was done by updating the app's color scheme, ensuring that all text and interface elements were easily readable in both light and dark modes. I cross referenced WebAIM contrast checker to ensure text met accessibility standards. The addition of light mode not only enhanced usability but also demonstrated a commitment to inclusivity and accessibility in app design.


Walk Through

1

Understanding Audience


User Testing/Interviews

In this particalar project, I was presented with the data Product Managers had collected from user testing and interviews. I analyzed the data to identify common pain points, user needs, and areas for improvement in the app's design. This analysis helped inform the redesign process and guided the development of solutions that addressed the specific issues users were facing. From this, I concluded that the lack of flexability the app provided was a major issue. Users wanted to be able to customize their experience and have more control over how they interacted with the app. This insight informed the decision to implement a light mode option, as it allowed users to choose the interface that best suited their preferences and needs.



2

Process


Design Goals

The main design goal was to improve the user experience by implementing a light mode option, allowing users to switch between light and dark themes based on their preferences and lighting conditions. This update aimed to enhance accessibility, readability, and overall usability of the app for all students navigating the campus.


  • Enhance readability and comfort

    Ensure text, icons, and interface elements are easy to read in a bright environment.

  • Maintain brand consistency

    Adapt the existing dark mode style while keeping the app’s visual identity intact.

  • Support accessibility standards

    Ensure sufficient contrast and usability for all users, including those with visual impairments

  • Provide a seamless toggle experience

    Allow users to switch between dark and light mode without disrupting their workflow or navigation.




3

UI Implementation


Adding a new look

With these goals in mind, I adapted Luminary’s existing interface into a light mode design. This process included testing contrast, readability, and visual hierarchy while preserving familiar navigation patterns.
